# Контент-планер

Откройте https://pongo.github.io/content-planner/

1. Добавьте карточки — это ваши темы.
2. Добавьте неделю и перетаскивайте в нее карточки.
3. Двойной клик редактирует карточку.
4. Нажатие ✔️ завершает неделю — карточки возвращаются в список.

Данные хранятся только в вашем браузере (в IndexedDB). Через гамбургер-меню можно удалить доску или экспортировать ее в Markdown. Для экспорта всей базы используйте браузерные расширения, например, IDBPort.

_Сафари очищает IndexedDB, если сайт не посещался 7 дней. Используйте Хром/Файрфокс._

## Фишки

- Если перетащить карточку с зажатым Ctrl — создастся копия.
- Двойной клик по пустому месту ячейки создает в ней карточку. Если при двойном клике зажать Ctrl, то будет отображен список карточек.
- Карточка из нескольких строк разделится пополам, но при завершении недели в список вернется только заголовок карточки.
- Если вторая строка карточки — это символ "=", то при завершении недели в список вернется карточка целиком.
- Если карточка начинается на "-", то при завершении недели она будет удалена.
